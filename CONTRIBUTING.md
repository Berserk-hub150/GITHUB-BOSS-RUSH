# Contributing to GitHub Boss Rush

Thanks for helping the arcade. Fork the repository, create a descriptive branch, test your changes locally, and submit a PR with steps to reproduce or screenshots when relevant.

- Keep the game playable without a paid account, API key or build tool.
- Use original or appropriately licensed artwork/audio, and include credits when required.
- Do not add trackers, collect visitors' GitHub tokens, or imply endorsements from creators.
- Validate GitHub usernames and keep the offline demo clearly labeled.
- For combat changes, test keyboard and touch; for layout changes, test narrow screens.
- Run `node --test tests/*.test.mjs` before submitting.

Good first contributions: better touch controls, additional sprite animations, contrast improvements, translated UI labels and gamepad support.
